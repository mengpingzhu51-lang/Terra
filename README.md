# Terra Resume Platform

Next.js resume generation, evaluation, and optimization platform.

## Run Locally

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env.local` and configure OpenRouter/Supabase variables.
3. Run the app:
   `npm run dev`

## Supabase

Run `supabase/schema.sql` in the Supabase SQL Editor before enabling persistence.
